# 11.5 D. 플랫폼과 인프라

에이전트가 외부 시스템을 대상으로 일하는 저장소들이다. **11개**다.

| 소분류 | 저장소 |
|---|---|
| D1 클라우드와 제품 연동 | 1 |
| D2 언어와 프레임워크 | 2 |
| D3 데이터와 검색 | 1 |
| D4 브라우저와 웹 자동화 | 5 |
| D5 에이전트 개발 SDK | 2 |

(수집 날짜: 2026-10-04)

**이 대분류는 150위 안에 가장 적게 들어온 영역이다.** 빅테크 공식 저장소 다수가 순위 밖이다. 각 절의 "그 밖에"를 같이 봐야 전체가 보인다.

---

## D1. 클라우드와 제품 연동

| 스타 | 저장소 | 스킬 | 언제 쓰나 | 주목할 점 |
|---|---|---|---|---|
| 20,875 | `google/skills` | 155 | Google Cloud, Ads 작업 | **`index.json`의 `description` 설계가 생태계 최고 수준** → [6.4](../part6/04-google.md) |

### 반드시 볼 것

**`index.json`이 이 책에서 추천하는 단일 학습 자료다.** `description` 쓰는 법을 배우려면 이걸 읽는 것이 가장 빠르다.

제외 조건마다 **어느 형제 스킬로 가야 하는지**를 적었다.

> **Don't use for** pure listing/discovery questions... — for those use `agent-platform-endpoint-management`. **Don't use for** running model evaluations (use `agent-platform-eval-flywheel` skill).

155개 규모에서 트리거 충돌을 관리하는 유일한 방법이고, 이걸 실제로 한 저장소다([1.5](../part1/05-triggering.md)).

`index.json`은 디스커버리도 푼다. `entrypoint`가 원격 URL이라 저장소를 복제하지 않고 스킬 하나를 가져올 수 있다.

### 그 밖에 (150위 밖)

| 스타 | 저장소 | 언제 쓰나 |
|---|---|---|
| 3,512 | `NVIDIA/skills` | Physical AI, 로보틱스, CUDA, RAG. **스캔과 서명을 거친 399개** |
| 3,075 | `microsoft/skills` | Azure 전반(205개). 플러그인 단위로 묶임 |
| 2,974 | `cloudflare/skills` | Durable Objects, Workers, Agents SDK |
| 1,854 | `timescale/pg-aiguide` | Postgres. MCP 서버와 스킬을 같이 배포 |
| 1,532 | `microsoft/azure-skills` | Azure MCP 설정 포함 |
| 296 | `vercel/vercel-plugin` | Vercel 생태계 |
| 272 | `aws-samples/sample-well-architected-skills-and-steering` | AWS Well-Architected |

### 범주의 상태

**자사 제품에 갇혀 스타가 낮다.** Azure를 안 쓰면 `microsoft/skills` 205개가 전부 쓸 데가 없다([7.6](../part7/06-why-individuals-win.md)).

그런데 **지식형이므로 갱신이 생명이고, 조직이 그걸 가장 잘한다.** `google/skills`가 수집 시점 이틀 전 푸시다. 개인 큐레이션 목록이 5개월씩 멈추는 것과 대조된다([7.4](../part7/04-awesome-lists.md)).

**그 플랫폼을 쓴다면 공식 저장소가 최선이다.** 스타수로 고르면 안 되는 대표적인 범주다.

## D2. 언어와 프레임워크

| 스타 | 저장소 | 스킬 | 언제 쓰나 | 주목할 점 |
|---|---|---|---|---|
| 7,644 | `android/skills` | 25 | 안드로이드 개발, 특히 **마이그레이션** | `agp-9-upgrade`, `migrate-xml-views-to-jetpack-compose` |
| 5,543 | `dotnet/skills` | 108 | .NET, C# 개발 | **평가 인프라가 생태계 최고다** → [6.5](../part6/05-microsoft.md) |

### 반드시 볼 것

**`dotnet/skills`는 .NET을 쓰지 않아도 읽을 가치가 있다.** 스타 5,543개로 1위의 1.9%인데, 평가 인프라에서 비교 대상이 없다.

```
eng/skill-validator/src/Evaluate/
├── AgentRunner.cs
├── AssertionEvaluator.cs
├── BaselineStore.cs      ← 기준선 저장
└── Comparator.cs         ← 비교

eng/eval-quality/
├── check_eval_quality.py
└── underpowered-allowlist.txt   ← 통계적 검정력 하한
```

**평가를 평가한다.** "자극 5개 미만이면 합격도 실패도 아닌 검정력 부족으로 분류한다"를 CI로 강제한다([9.2](../part9/02-measuring-quality.md)).

`eng/eval-quality/README.md`가 생태계에서 평가 설계를 배울 최고 자료다.

### 마이그레이션 스킬이라는 유형

`android/skills`의 `agp-9-upgrade`가 흥미롭다. **스킬에 유효기간이 있는 경우다.**

버전 업그레이드와 구식 API 전환은 절차가 길고 매번 같아서 스킬에 적합하다. 그리고 전환기가 끝나면 쓸 데가 없어진다.

**이런 스킬은 폐기 시점을 적어 두는 것이 맞다.** 생태계에 폐기 표시 관례가 없어서([9.1](../part9/01-star-traps.md)) 낡은 마이그레이션 스킬이 계속 트리거될 수 있다.

### 범주의 상태

**거의 비어 있다.** 주요 언어 중 공식 스킬 저장소가 있는 것은 .NET과 안드로이드뿐이다.

Python, JavaScript, Go, Rust, Java에 해당하는 저장소가 150위 안에 없다. `samber/cc-skills-golang`(3,379)이 150위 밖에 있다.

**빈 자리다.** 다만 대상 인구가 커도 스타가 보장되지 않는다는 점을 감안해야 한다 — 언어 스킬은 지식형이고 드라마가 없다.

## D3. 데이터와 검색

| 스타 | 저장소 | 스킬 | 언제 쓰나 | 주목할 점 |
|---|---|---|---|---|
| 6,333 | `anysearch-ai/anysearch-skill` | 1 | 에이전트가 실시간 웹 검색을 할 때 | 일반 검색 + 버티컬 도메인 검색 |

### 범주의 상태

**실제로 빈 자리다.** 데이터베이스, 데이터 분석, ETL, BI에 해당하는 저장소가 150위 안에 하나도 없다.

150위 밖에 `timescale/pg-aiguide`(1,854)와 `alibaba/zvec`(16,059, 벡터 DB 제품)가 있는 정도다.

**수요와 공급이 가장 크게 어긋난 영역이다.** 데이터 작업은 반복 절차가 많고(스키마 파악, 쿼리 작성, 결과 검증) 스킬에 적합한데 저장소가 없다.

이유로 추정되는 것이 있다. **데이터 작업은 조직마다 스키마가 달라서 공유 가능한 부분이 작다.** 범용 스킬로 만들 수 있는 것은 방법론 수준이고, 그건 A1과 겹친다.

## D4. 브라우저와 웹 자동화

| 스타 | 저장소 | 스킬 | 언제 쓰나 | 주목할 점 |
|---|---|---|---|---|
| 35,581 | `JCodesMore/ai-website-cloner-template` | 1 | 웹사이트를 복제할 때 | **저작권 확인 필요** |
| 16,798 | `citrolabs/ego-lite` | 2 | 로그인 상태를 유지한 채 브라우저 자동화 | 세션 공유가 핵심 기능이자 위험 지점 |
| 6,644 | `SawyerHood/dev-browser` | 1 | 에이전트에게 웹 브라우저를 줄 때 | 가장 단순한 형태 |
| 6,258 | `gosom/google-maps-scraper` | 1 | 구글 맵 데이터 수집 | **이용약관 확인 필요** |
| 6,087 | `browser-act/skills` | 103 | 안티봇 우회가 필요한 자동화 | **사람에게 넘기는 경로를 설계에 포함** |

### 먼저 볼 것

**단순한 것부터 시도한다.** 브라우저가 필요할 뿐이면 `dev-browser`로 충분하다. 103개 스킬 번들을 설치할 이유가 없다.

`browser-act/skills`가 "사람에게 넘긴다(hand off to humans)"를 설명에 적은 점은 좋은 설계다. **자동화가 막히는 지점을 인정하고 경로를 만든 것**이고, 캡차나 2단계 인증에서 필요하다.

### 반드시 확인할 것

**이 범주는 법적 위험이 가장 크다.**

| 위험 | 해당 저장소 |
|---|---|
| 저작권 | 웹사이트 복제 |
| 이용약관 위반 | 스크래핑, 안티봇 우회 |
| 세션 탈취 | 로그인 상태 공유 |

**`ego-lite`의 "로그인된 브라우저 상태 공유"가 특히 민감하다.** 에이전트에게 세션 쿠키를 넘기는 것이고, 스킬이 악성이면 그 세션으로 할 수 있는 모든 일이 가능하다.

스킬 26.1%에 취약점이 있다는 통계를 감안하면([9.3](../part9/03-supply-chain.md)) 이 범주는 **설치 전 스캔이 선택이 아니다.**

### 범주의 상태

**5개로 D에서 가장 많다.** 브라우저 자동화는 "수단이 없어서 못 하는" 전형적인 결핍이라 수요가 분명하다.

다만 [1.4](../part1/04-boundaries.md)의 기준으로 보면 **상당수가 MCP 서버의 영역이다.** 외부 접근과 인증 관리가 필요하기 때문이다. 스킬 형태로 배포하면 그 관리를 스킬이 떠안는다.

## D5. 에이전트 개발 SDK

| 스타 | 저장소 | 스킬 | 언제 쓰나 | 주목할 점 |
|---|---|---|---|---|
| 10,716 | `mcp-use/mcp-use` | 6 | MCP 앱이나 서버를 만들 때 | 프레임워크가 본체 |
| 6,043 | `google/agents-cli` | 15 | Google Cloud에 에이전트를 배포할 때 | 설명에 "**평가하고**"가 들어 있다 |

### 주목할 점

**도구와 스킬을 같이 배포하는 패턴이다.** 도구가 수단을 주고 스킬이 잘 쓰는 법을 준다([1.4](../part1/04-boundaries.md)).

MCP 서버가 도구 20개를 제공하면 에이전트는 그걸 **쓸 수** 있게 되지만 **잘 쓰는 법**은 모른다. 어떤 순서로 호출할지, 어떤 조합이 위험한지는 도구 정의에 안 들어간다.

**공식 번들의 `mcp-builder`가 같은 자리에 있다**(`anthropics/skills`, 236줄 + 번들 10개 파일). MCP 서버 만드는 법을 가르치는 스킬이다 — MCP와 스킬이 경쟁 관계가 아니라는 증거다([6.1](../part6/01-anthropic-skills.md)).

## D 전체에서 읽히는 것

### 150위 안에 11개뿐이다

A(17), C(14)보다 적다. 그런데 **150위 밖에 공식 저장소가 7개 이상 있다.**

| 구간 | 저장소 |
|---|---|
| 150위 안 | 11 |
| 150위 밖 (확인된 것) | 7+ |

**이 범주는 순위로 보면 실제보다 작아 보인다.** 자사 제품 사용법은 대상 인구가 제한되므로 스타가 안 붙는다([7.6](../part7/06-why-individuals-win.md)).

### 지식형이 몰려 있고, 그래서 갱신이 결정적이다

D1과 D2는 거의 전부 지식형이다. API와 SDK가 바뀌면 틀린 답을 자신 있게 낸다 — **없는 것보다 나빠진다**([4.2](../part4/02-three-types.md)).

**이 범주에서는 마지막 푸시 날짜가 스타수보다 중요하다.** 선택 기준을 뒤집어야 하는 유일한 대분류다.

### 빈 자리가 분명하다

| 영역 | 상태 |
|---|---|
| 데이터베이스, 분석 | 거의 없음 |
| 주요 언어 (Python, JS, Go, Rust, Java) | 150위 안에 없음 |
| CI/CD, 배포 파이프라인 | 번들 안의 스킬로만 존재 |
| 관측성, 모니터링 | `addyosmani`의 스킬 하나 |

만들 자리를 찾는다면 여기다. 다만 **대상 인구가 커도 스타가 보장되지 않는다.** 지식형이고 드라마가 없기 때문이다.
