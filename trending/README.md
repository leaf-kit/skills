# 추가 수집 — 트렌딩에서 찾은 신규 스킬

5부, 6부, 7부, 8부, 11부는 [`data/collect.sh`](../data/collect.sh)와 [`data/classify.sh`](../data/classify.sh)가 월 1회 정식으로 수집한 458개 저장소를 다룬다. 이 섹션은 그 바깥이다. [github.com/trending](https://github.com/trending) 등에서 **그 사이에** 눈에 띈 저장소를 발견 즉시 적어 두는 곳이다.

## 왜 따로 두는가

정식 수집은 토픽 검색 + 고정 저장소 목록이라 재현 가능하고, "458개"라는 숫자가 `collect.sh`를 다시 돌리면 그대로 나온다. 트렌딩 페이지는 매일 바뀌고 사람이 골라야 해서 같은 방식으로 재현할 수 없다. 섞으면 본문의 핵심 전제("숫자를 손으로 적지 않는다")가 깨진다.

그래서 여기 쌓인 저장소는 **아직 본문의 458개/126개에 들어가지 않은 후보**다. 분기 정식 재수집에서 계속 활성 상태로 확인되면 정식 데이터셋에 옮긴다([9.6](../part9/06-update-policy.md)).

## 읽는 법

- 월별로 파일이 하나씩 쌓인다. 새 달이 되면 새 파일이 생긴다.
- 같은 달 안에서 새로 찾으면 그 달 파일에 항목이 추가된다 — 파일을 지우거나 덮어쓰지 않는다.
- 각 항목에는 **발견 날짜**와 **그 날짜의 스타수**가 붙는다. 트렌딩에 오르는 저장소는 보통 하루에도 수천씩 스타가 늘기 때문이다.
- 확인 수준은 **요약 리뷰**다([9.6](../part9/06-update-policy.md)의 구분). 설명과 파일 트리, README 첫 문단만 보고 썼다. 정밀 리뷰(전체 코드를 열어 본 리뷰)는 정식 데이터셋에 들어간 뒤 해당 부에서 한다.
