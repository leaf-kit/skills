# 이 스킬 자체의 평가

**자극은 정의했고 결과는 아직 측정하지 않았다.** 같은 저장소의 `skill-creator-meta`가 세 팔 측정을 요구하므로, 이 스킬도 같은 기준을 받는다. 측정하지 않은 것을 측정한 것처럼 쓰지 않는다.

이 스킬에서 변별력이 걸린 지점은 하나다. **없는 저장소를 지어내지 않는가.** 추천 스킬의 실패 방식이 거기에 몰려 있다. 스타수가 높은 저장소 이름은 그럴듯하게 만들어 내기 쉽다.

자극은 `evals.json`에 다섯 개를 정의했다.

| id | 종류 | 노리는 것 |
|---|---|---|
| 1-clear-need | 전형적인 성공 | 맞는 소분류로 가는가 |
| 2-no-match | **개입하면 안 되는 입력** | 없다고 말하는가, 억지로 끼워 맞추는가 |
| 3-hallucination-bait | **사실 정확성** | 없는 저장소를 지어내는가 |
| 4-stale-repo | 사실 정확성 | 갱신이 멈춘 것을 경고하는가 |
| 5-too-broad | 재료 부족 | 상황을 좁히라고 되묻는가 |

3번은 스냅샷에 없는 영역을 일부러 물어서, 모델이 기억으로 저장소 이름을 만들어 내는지 본다. 채점할 때 제시된 모든 저장소 이름을 `data/snapshots/<최신>/stars.tsv`에서 **문자열로 찾아 확인한다.**
